QUICK START - READ THIS FIRST!
-------------------------------

This pipeline extracts real observational climate data (temperature and PM2.5)
for Soweto, South Africa from Google Earth Engine (2014-2024).

WHAT YOU NEED:
  1. Python 3.8 or higher
  2. Google Account (for Earth Engine access)
  3. Internet connection
  4. 15-30 minutes for first run

QUICK SETUP (First Time):
  1. Open Terminal
  2. Navigate to this directory:
     cd "/Users/craig/Library/Mobile Documents/com~apple~CloudDocs/Admire"
  3. Run these commands:
     python3 -m venv venv
     source venv/bin/activate
     pip install -r requirements.txt
     earthengine authenticate
     
  4. Follow browser prompts to authenticate with Google

RUN THE PIPELINE:
  ./run_pipeline.sh
  
  OR manually:
  source venv/bin/activate
  python soweto_climate_pipeline.py

VALIDATE RESULTS:
  python validate_extraction.py

WHERE ARE MY RESULTS?
  climate_data_output/
    ├── soweto_temperature_raw.csv         (hourly temperature)
    ├── soweto_pm25_raw.csv                (3-hourly PM2.5)
    ├── soweto_temp_monthly_stats.csv      (monthly stats)
    ├── soweto_temp_seasonal_stats.csv     (seasonal stats)
    ├── soweto_temp_annual_stats.csv       (annual stats)
    ├── soweto_pm25_monthly_stats.csv      (monthly PM2.5 stats)
    ├── soweto_pm25_seasonal_stats.csv     (seasonal PM2.5 stats)
    ├── soweto_pm25_annual_stats.csv       (annual PM2.5 stats)
    ├── quality_report.json                (data quality metrics)
    └── soweto_climate_extraction.log      (execution log)

DATA SOURCES:
=============
  Temperature: ERA5-Land (ECMWF reanalysis, 11km, hourly)
  PM2.5:       CAMS (Copernicus atmospheric reanalysis, 40km, 3-hourly)
  
  Both are validated, observation-assimilated datasets suitable for research.

EXECUTION TIME:
===============
  Full 11-year extraction: 15-30 minutes
  Depends on Google Earth Engine server load

GETTING HELP:
=============
  1. Check the log: climate_data_output/soweto_climate_extraction.log
  2. Read: TROUBLESHOOTING.md
  3. Run validation: python validate_extraction.py
  4. Check GEE status: https://status.earthengine.google.com/

COMMON ISSUES:
==============
  "No module named 'ee'" → pip install earthengine-api
  "Authentication failed" → earthengine authenticate
  "Memory limit exceeded" → Edit pipeline: BATCH_SIZE_MONTHS = 3
  Empty CSV files → Check log file for errors
