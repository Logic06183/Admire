CRITICAL FINDING: UNIT CONVERSION ERROR
================================================================================

The PM2.5 data has a FUNDAMENTAL UNIT ERROR:
- CAMS NRT provides data in kg/m³ (kilograms per cubic meter)
- Data was NEVER converted to μg/m³ (micrograms per cubic meter)
- Conversion factor needed: ×10^9 (multiply by 1 billion)

This means ALL PM2.5 values in the current dataset are WRONG by a factor of 1 billion.

CORRECTED PIPELINE CODE
================================================================================

File to fix: soweto_climate_pipeline.py

WRONG CODE (lines 126-128):
----------------------------
def micrograms_to_micrograms(pm25: float) -> float:
    """Pass-through for PM2.5 (already in µg/m³)."""
    return pm25

CORRECTED CODE:
---------------
def kg_to_micrograms_per_m3(pm25_kg: float) -> float:
    """
    Convert PM2.5 from kg/m³ to μg/m³.
    CAMS NRT provides PM2.5 in kg/m³.
    Conversion: 1 kg/m³ = 10^9 μg/m³
    """
    return pm25_kg * 1e9

ALSO ADD (line 288 in extract_pm25_batch):
------------------------------------------
data['pm25'] = data['pm25'].apply(kg_to_micrograms_per_m3)
